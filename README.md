# Dr. Z Academy - Espacio de Experimentación en Línea

¡Bienvenido al repositorio oficial del nuevo sitio web de la **[Dr. Z Academy](https://drz.academy/)** para herramientas interactivas!

Este espacio ([drz-academy.github.io](https://drz-academy.github.io)) nace como un entorno de experimentación en línea para alojar todas las aplicaciones web, simuladores interactivos, demos y el contenido detallado de nuestros cursos de ciencia, astronomía y programación que hemos desarrollado.

A diferencia del [sitio oficial principal](https://drz.academy/) (centrado en información general y la tienda), este rincón está diseñado puramente para la **interacción didáctica** y el código.
