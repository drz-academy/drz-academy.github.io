<p>Llevamos varios años realizando diferentes actividades de divulgación científica como charlas, cursos y libros (¡en proceso!) con el objetivo de compartir la curiosidad por la ciencia y la tecnología. A lo largo de este recorrido, hemos tenido la oportunidad de crear algunas herramientas didácticas usando código (Python, HTML, JavaScript) que queremos ahora compartir con ustedes. Para ello hemos decidido crear un nuevo sitio web <strong><a href="https://drz-academy.github.io/" style="color: #0056b3;">drz-academy.github.io</a></strong> para la experimentación en línea y el acceso a estos recursos.</p>

<p>En este nuevo sitio encontrarán aplicaciones web que desarrollamos para los cursos, por ejemplo un <a href="https://drz-academy.github.io/apps/lighting-black-holes/" style="color: #0056b3; font-weight: bold;">simulador de la óptica de agujeros negros</a>, y páginas de demostración que te permitirán experimentar con conceptos científicos como <a href="https://drz-academy.github.io/demos/optica-activa/" style="color: #0056b3; font-weight: bold;">¿cómo se verían las imágenes del JWST si los espejos estuvieran desalineados?</a>, entre otras.</p>

<p>Adicionalmente estamos publicando en esta página la información detallada de los cursos, la misma que en el pasado compartíamos en la forma de archivos de GoogleDocs pero que ahora se puede ver de forma más cómoda, incluso en dispositivos móviles desde la web (<a href="https://drz-academy.github.io/cursos/python-fin-del-mundo/" style="color: #0056b3; font-weight: bold;">como en este ejemplo de nuestra nueva Masterclass "Extraterrestres"</a> o en el curso, ahora permanente, de <a href="https://drz-academy.github.io/cursos/python-fin-del-mundo/" style="color: #0056b3; font-weight: bold;">Python para el fin del mundo</a>.</p>
